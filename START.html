1. Стенд: наблюдение последовательностей

Один шаг не равен секунде. Значения задаются вручную. Состояние запоминается только внутри последовательности. Перед независимым опытом нажмите «Новый опыт».

Шагов пока нет.

2. Испытательная лаборатория

Сначала запишите ожидаемые результаты по требованиям. Каждый сценарий начинается с pump=false, vent=false, fault=false. Для проверки неверных типов вводите JSON здесь, а не в числовых полях стенда.

Результатов пока нет.

3. Инженерное решение

Показатели сами по себе не разрешают выпуск. Дополните шаблон отчёта: какие требования проверены, какие риски остаются, что изменилось после исправления кандидата, почему набор достаточен для учебной приёмки. Отчёт стенда не заменяет ваш вывод.

Данные не отправляются в сеть и не сохраняются после закрытия страницы. Скачивайте тесты и отчёты. Изменение JSON делает старый отчёт недоступным до повторного запуска.
